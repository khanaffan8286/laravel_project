ORM -> ORM STANDS FOR OBJECT RELATIONAL MAPPING 

IT AN TECHNIQE THAT HELPS YOU TO INTRACT YOU WITH DATABASE USING PHP OBJECTS INSTED OF WRITTING RAW SQL QUERIES.


LARAVEL USES ITS OWN ORM CALLED ELOQUENT ORM 

With Eloquent, each database table is represented by a model (class).

🔹 Simple Example

Instead of writing SQL like this:

SELECT * FROM users WHERE id = 1;

You can use Eloquent:

$user = User::find(1);
Here:

User is a model (represents the users table)
find(1) fetches the record with ID = 1

// Get all users
$users = User::all();

// Insert
User::create(['name' => 'John']);

// Update
$user->update(['name' => 'Jane']);

// Delete
$user->delete();


LARAVEL ORM (ELOQUENT ORM) PROVIDES SIMPLE METHODS FOR HANDLING REALTIONSHIP.


1. ONE TO ONE RELATIONSHIP 

ONE RECORD CONNECTED TO ONLY ONE OTHER RECORD.


EXAMPLE -> ONE USER -> ONE PROFILE 

USER TABLE 
ID  NAME 

PROFILE TABLE 
ID USER_ID PHONE 


USER MODEL 

public function profile(){
      return $this->hasone(Profile::class);
}

PROFILE MODEL 

public function user(){
    return $this->belongsTo(User::class);
}

IN CONTROLLER NOW YOU CAN GET THAT

$farm = Farm::find(1);
$farm->profile;

ONE RECORD CAN CONECTED TO MANY RECORDS

3️⃣ Many-to-Many Relationship
Meaning

Many records can belong to many records.

Example:

Many Students ↔ Many Courses

A student can join many courses.
A course can have many students.

🔹 Tables
students table
id	name
1	Affan
courses table
id	title
1	Laravel
course_student table (Pivot Table)
student_id	course_id
1	1
🔹 Models
Student Model
public function courses()
{
    return $this->belongsToMany(Course::class);
}
Course Model
public function students()
{
    return $this->belongsToMany(Student::class);
}


4️⃣ Has One Through
Meaning

Access another model through an intermediate model.

Example:

Country → User → Post

A country has users.
Users have posts.

Country can access posts through users.


public function posts()
{
    return $this->hasManyThrough(Post::class, User::class);
}
